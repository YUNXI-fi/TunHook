# TunHook
TunHook 是一款自托管的端口转发与内网穿透工具。提供 TCP / UDP / HTTP / HTTPS 端口映射、统一网关与 frpc 代理，兼容 FRP、MEFrp、LoliaFrp 与 Cloudflare Tunnel；每条通道可独立设置限速、连接数、PROXY protocol v2、源端 TLS、UDP 会话参数、日志与 IP 过滤；内置 TLS 证书申请续期、域名解析管理、IP 归属地库、通道健康检测与 Webhook 通知；支持错误页自定义、导航页、全量备份恢复、仪表盘布局与模块开关，适配移动端；ROOT 版支持桌面图标自动打包安装、Docker 端口扫描、连通性测试与本机直连优化。
